# Documentation Capture Assets

`kenney-new-platformer/` contains the character, terrain, background, and impact sprites used by
the documentation capture scenes. They come from Kenney's
[New Platformer Pack](https://kenney.nl/assets/new-platformer-pack), version 1.1.

The pack is released under Creative Commons Zero (CC0). The original license text is kept
beside the selected assets in `kenney-new-platformer/LICENSE.txt`.

`kenney-input-prompts/` contains the platform-neutral controller used by the haptics capture.
It comes from Kenney's [Input Prompts](https://kenney.nl/assets/input-prompts) pack, version 1.5.
That pack is also CC0; its original license is kept in `kenney-input-prompts/LICENSE.txt`.
